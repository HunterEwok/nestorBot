# Плеер песен (Telegram Mini App)

Telegram на компьютере не проигрывает YouTube внутри себя и открывает браузер. Эта страница — встроенное приложение бота: кнопка «▶️ Плеер» под карточкой песни открывает `https://t.me/<бот>/<приложение>?startapp=<id видео>`, Telegram показывает страницу в своём окне, а она — официальный плеер YouTube с этим видео.

- `index.html`, `player.js`, `player.css` — вся страница, без сборки и без сервера. Публикуется в отдельном публичном репозитории через GitHub Pages.
- Страница берёт id видео только из `tgWebAppStartParam` (или `?v=` для проверки в браузере) и пропускает только 11 символов `[A-Za-z0-9_-]`.
- Content-Security-Policy разрешает только скрипт Telegram и рамку `youtube-nocookie.com`. YouTube получает Referer только с адресом сайта.
- Данные зрителя, которые Telegram передаёт приложению (initData), страница не читает и никуда не отправляет.

Бот добавляет кнопку, только если в `.env` задано `MUSIC_PLAYER_APP=<short name из BotFather>` (см. `nestor/bot/music.py`, `player_link`).

Установка по шагам: `player-setup.md` в файлах проекта.
